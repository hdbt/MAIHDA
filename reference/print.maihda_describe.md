# Print a MAIHDA sample description

Print a MAIHDA sample description

## Usage

``` r
# S3 method for class 'maihda_describe'
print(x, digits = x$digits, ...)
```

## Arguments

- x:

  A `maihda_describe` object from
  [`maihda_describe`](https://hdbt.github.io/MAIHDA/reference/maihda_describe.md).

- digits:

  Decimal places (defaults to the value stored on `x`).

- ...:

  Additional arguments (not used).

## Value

Invisibly, `x`.
