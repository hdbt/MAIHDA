# Validate a sampling-weights specification

Validate a sampling-weights specification

## Usage

``` r
maihda_validate_sampling_weights(sampling_weights, data)
```

## Arguments

- sampling_weights:

  A single character string naming a numeric column of `data` holding
  the individual sampling (design) weights.

- data:

  The data frame the weights must live in.

## Value

The validated column name.
