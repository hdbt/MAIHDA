# Run MAIHDA Shiny Application

Launches a Shiny graphical user interface that exposes core functions of
the MAIHDA package, allowing for visual data exploration, model fitting,
and performance visualization.

## Usage

``` r
run_maihda_app()
```

## Value

No return value, called to launch the shiny app.

## Examples

``` r
if (FALSE) { # \dontrun{
run_maihda_app()
} # }
```
