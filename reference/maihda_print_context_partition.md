# Print the stratum vs. context partition of a contextual cross-classified summary

Print the stratum vs. context partition of a contextual cross-classified
summary

## Usage

``` r
maihda_print_context_partition(ctx)
```

## Arguments

- ctx:

  The `context` list from a contextual
  [`summary.maihda_model`](https://hdbt.github.io/MAIHDA/reference/summary.maihda_model.md)
  (a model fitted with `fit_maihda(context = )`).

## Value

No return value, called for side effects.
